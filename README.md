# Cook County Housing Modeling

End-to-end housing analytics and price modeling workflow for Cook County property data. The notebook covers data loading, feature exploration, feature engineering, linear regression modeling, error analysis, and prediction generation.

## Files
- `cook_county_housing_modeling.ipynb` — combined analysis and modeling notebook
- `cook_county_housing_modeling.py` — script version of the notebook code
- `requirements.txt` — Python dependencies inferred from the notebook

## Data
Place the following files in the project root before running the notebook:
- `cook_county_train.csv`
- `cook_county_train_val.csv`
- `cook_county_contest_test.csv`
- `cook_county_data.zip` if using the zipped source workflow

## Notes
Generated outputs are intentionally excluded so the repository stays clean and reproducible.
